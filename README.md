# Первая домашка

## 1. Первая программа создает случайные данные используя Faker библиотеку. Формат данных следующий:
Генерит от 10 до 100 записей (в виде массива джсонов)

{
"id": UUID,
"name": string, 
"age" : int,
"salary" : int,
"PROFESSION": (ARTIST,IT,ACCOUNTANT)
}

Она запускается и работает постоянно и генерит по файлику раз в 30 секунд. Файлик имеет формат
текущее_время_data.txt где текущее время это System.currentmilisseconds например 213131313_data.txt.
На старте программы вы указываете куда сохранять сгенеренные папки.

## 2. Вторая программа 

Эта программа запускается 1 раз, ей передается папка где лежат файлы сгенеренные первой программой
а также куда сохранять результат аналитики. 
Цикл программы следующий: 
1. Программа анализирует папку с генеренными первой программой файлы и сверяет ыли ли они уже проанализированны
ранее.
2. Если файл новый то он агреггирует все записи по профессии и дает пишет результат сколько в сумме запрата
по профессии и сколько средний возраст. 
3. Результат он сохраняет в фиде массива json (по одной записи для каждой из профессии)

{
"PROFESSION": (ARTIST,IT,ACCOUNTANT),
"average_salary": int,
"average_age": int
}

4. После этого он отправляет этот емейл (пример отправки смотрите в классе Main, токен нельзя пушить 
в гитхаб, его передайте через  параметр на старте программы). В теле он описывает какой файл был проанализирован
и время когда этто случилось. В приложении он прикрепляет файл результат аналитики. 

## 3. Девопсина

После того обе программы написаны запуште их в разные ветки но в один репозиторий. Выкачайте обе
и стартаните первую чтобы она генерила файлы и работала без перерыва. Затем запускайте вторую но 
каждые 30 секунд (напишите небольшой bash cкрипт для этого).

В результате программы проверяйте свой емейл и смотрите как приходят отчеты с файлами результатами аналитики.

Старайтесь сделать без генерации кода но когда прям совсем не понимаете то ок. Пишите в чат если
будут непонятки или вопросы. Задача полностью новая, потенциально есть недочеты.
