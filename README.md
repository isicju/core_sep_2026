# Третья домашка, большая по размеру.

## 1. Первая часть - практика выбора коллекций.

В классе API нужно загрузить пользователей по ссылке (там указано)
Смысл задачи в том, чтобы после загрузки пользователей создать дополнительные
коллекции (вроде кэшей) из которых потом можно быстро вытаскивать (или добавлять итд)
данные в зависимости от сигнатуры методов API класса. 

## 2. Вторая часть - функционалка

В пакете functional лежат 4 класса которые нужно заполнить в зависимости от сигнатур методов.


## 3. Исключения

В пакете exceptions есть 3 класса, в каждом из них есть методы которые нужно заполнить так
чтобы они внутри воспроизводили ситуации приводящие к исключеням, также в папке тестов
можно проверить что код написан верно.
