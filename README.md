# Вторая домашка - создание сервиса генерации файлов по тексту с валидацией.

## 1. Цель домашки написать сервис который создает билеты на самолет, результатом программы
после нажатия с фронта должен скачаться файл с данными. Формат файла выбирается пользователем.
В файле должны быть данные пользователя, стоимость билета.

## 2.  Для каждого из входящих файлов должна быть валидация, 

Для всех билетов 
Запрос не должен содержать спамных сообщений. Исполоьзуйте сервис SpamCheckService, 
если уровень спама должен быть меньше 0.1 (значение spamProbability). Чтобы сервис заработал
создайте токен на сайте openrouter. помните что в день дается лишь 50 бесплатных запросов.

для авиа
1. Количество багажа не более 3
2. Возраст от 21
для жд
1. Количество багажа не более 5
2. Возраст от 18

Если данные невалидны то кидайте ошибку 400 с описанием причины. 

## 3. Алгоритм расчета стоимости
расчет стоимости билета (для авиации стоимость
1000 плюс 500 за каждый багаж, для жд 750 и 300 но первые 2 багажа бесплатно)

## 4. Генерация файла. 
Функция public byte[] processRequest возвращает массив байт, в зависимости от типа
сюда дожен возвращаться массив байт либо pdf либо png файла который должен  быть сгенерен
можете использовать llm чтобы это сделать.

## 4. Логируйте время вызова spam checker сервиса
Используя прокси паттерн замеряйте по времени время каждого из вызовов. 

## 5. Задеплойте на сервер
Проверьте что ваш сервис работает и задеплойте его на сервер.

Часть с http сервером менять не надо, если хотите то делайте это по минималке, это не входит
в часть домашки.

Смысл задачи в том чтобы написать промышленное приложение и использовать OOP чтобы сделать
код внутри RequestProcessor читаемым. На входе у метода этого класса лишь голые поля,
вам нужно написать нужные классы, интерфейсы и применять паттерны итд. Проявите фантазию.
